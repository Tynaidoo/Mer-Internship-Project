# Mer Internship Project

**Roadmap to an Effective Internship Experience**

A public-facing prototype website for an internship learning course focused on workplace readiness, professional skills, digital and AI literacy, self-management, communication and career development.

## Current status

This first version contains the landing page prototype.

## Landing page features

- Responsive HTML/CSS/JavaScript implementation
- Colour palette inspired by the merSETA visual identity
- Animated vehicle assembly hero graphic built with inline SVG and CSS
- Five-module course roadmap based on the supplied Internship Course document
- Accessible semantic structure and reduced-motion support
- GitHub Pages-ready static site

## Course modules represented

1. Welcome
2. Preparing for Success at Work
3. Digital Environment & AI Use
4. Learning Fears & Time Management
5. Communication

## Run locally

Open `index.html` in a browser. No build process is required.

## Repository name

GitHub repository URLs cannot contain spaces, so the repository is named:

`Mer-Internship-Project`

The display/project name remains **Mer Internship Project**.
