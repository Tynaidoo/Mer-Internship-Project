Module 5 · Session 2

Introduction to the Microsoft 365 Ecosystem

Learn how Microsoft 365 applications connect to support professional communication, collaboration, file management, analysis and presentation.

Microsoft 365 • Digital Collaboration • Productivity

Purpose

This session introduces you to the Microsoft 365 ecosystem and develops your ability to use Microsoft applications appropriately in a professional workplace environment. Microsoft 365 is approached as an integrated digital workplace ecosystem rather than as a collection of separate software applications.

Learning Outcomes

  • Identify the main Microsoft 365 applications used in professional workplaces.
  • Explain the workplace purpose of Outlook, Teams, OneDrive, Word, Excel, PowerPoint and SharePoint.
  • Explain how Microsoft applications can be integrated to complete a workplace task.
  • Select an appropriate Microsoft application for a specific workplace requirement.
  • Demonstrate basic digital workplace practices relating to communication, collaboration, file management and information presentation.
Spark

Is digital competence about knowing how to use technology, or knowing how to use technology effectively?

Microsoft 365 as a Digital Workplace Ecosystem

Microsoft 365 is an integrated ecosystem that allows employees to communicate, create, store, share and present information.

Microsoft applicationWorkplace purpose
OutlookProfessional email, calendars, appointments and meeting invitations
Microsoft TeamsTeam communication, meetings, collaboration and access to shared files
OneDrivePersonal work-file storage, synchronisation and file sharing
WordReports, letters, minutes, proposals and professional documents
ExcelData organisation, calculations, analysis, budgets and reporting
PowerPointPresentations, briefings and visual communication
SharePointOrganisational document storage, shared resources and collaborative workspaces
Outlook → Teams → OneDrive / SharePoint → Excel → Word → PowerPoint

The key concept is that these applications are interconnected. A workplace task may require several applications rather than one.

Key principle

A professional presentation should help an audience understand information and make decisions.

Activity 5.2.1

Microsoft 365 Workplace Challenge

Apply your understanding of the Microsoft ecosystem to each workplace situation.

Scenario A

Your supervisor asks you to confirm your attendance at a meeting.

Which Microsoft application would you use, and why?

Scenario B

You need to arrange a meeting with four colleagues working on the same project.

Which Microsoft application would you use? Explain your answer.

Scenario C

Three interns need to work on the same report without creating multiple versions.

Which Microsoft tools could support this task? Explain your answer.

Scenario D

Your supervisor gives you a spreadsheet containing monthly expenditure and asks you to identify trends.

Which Microsoft application would you use and what functions might you need?

Scenario E

You need to present your findings to the management team.

Which Microsoft application would you use? Explain your answer.

Activity 5.2.2

Complete the Digital Workplace Task

Workplace scenario

You are an intern in the administration department. Your supervisor asks you to prepare a monthly project update. You receive information from team members, need to analyse project data, prepare a short written report and present the main findings at a team meeting.

Design a complete Microsoft 365 workflow for the task.

StageYour application and approach
Communication — How will you communicate with team members?
Collaboration — Where will you discuss and work on the project?
File management — Where will you store the documents?
Data analysis — Which application will you use?
Report writing — Which application will produce the report?
Presentation — Which application will present the findings?

Possible workflow

Outlook → Teams → OneDrive / SharePoint → Excel → Word → PowerPoint → Teams

Alternative workflows are valid when you can justify why the selected tools fit the task.

Practical challenge

If computers are available, complete at least one practical action:

  • Create an Outlook meeting.
  • Create a Teams channel or chat.
  • Create a folder in OneDrive.
  • Create and format a Word document.
  • Enter and calculate data in Excel.
  • Create a simple Excel chart.
  • Create a three-slide PowerPoint presentation.

Debrief

1. Why did you select each application?

2. How did the applications connect?

3. What could go wrong if files were poorly organised?

4. What would make your digital communication professional?

5. Which Microsoft skill do you need to improve before starting your internship?

The Excel component is particularly important because Kirsten et al. (2025) provide empirical evidence that practical Excel interventions can improve students' skills and self-perceptions of workplace readiness.

Checklist & Reflection

  • I can identify the main Microsoft 365 applications used in professional workplaces.
  • I can explain the workplace purpose of Outlook, Teams, OneDrive, Word, Excel, PowerPoint and SharePoint.
  • I can explain how Microsoft applications can be integrated to complete a workplace task.
  • I can select an appropriate Microsoft application for a specific workplace requirement.
  • I can demonstrate basic digital workplace practices relating to communication, collaboration, file management and information presentation.

Reflection

How confident were you in using Microsoft 365? How confident are you now?
